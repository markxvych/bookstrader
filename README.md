# Book Trader

A web app for managing personal book collections and swapping books with other users.

**Stack** · Next.js, TypeScript, Tailwind CSS, shadcn/ui, Supabase (Auth, PostgreSQL, Storage)

## Features

- Sign up, sign in, and edit your profile.
- Add, edit, and delete books with uploaded or linked covers.
- Browse, search, and sort the paginated catalog.
- Request book swaps. Accepting a request swaps ownership of both books.
- Manage users and edit or delete any book through the admin panel.
